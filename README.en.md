# token-diet

Claude Code plugin to spend fewer tokens without losing quality: compact rules, smaller screenshots, `/clear` and `/compact` buttons, and a token audit.

- Rules for code and answers that are added once per session.
- Images are resized before they are read.
- Suggests clearing or compacting when it is worth it.
- `/token-audit` shows where the tokens of a session went.

```bash
npm ci && npm run lint && npm test
```
